### Lab 5 — Database Storage Management

Performed Oracle database storage administration and capacity management.

Hands-on work included:

- Creating tablespaces
- Creating and managing datafiles
- AUTOEXTEND configuration
- Resizing datafiles
- Adding additional datafiles
- Monitoring used and available storage
- Read-only tablespaces
- Temporary tablespaces
- Storage utilization queries
- Testing storage limitations

The lab demonstrates how storage limitations affect database operations
and how database storage can be expanded and managed.

## Documentation Approach

Each section of this repository is designed to demonstrate not only
what was configured, but also how the work was performed and validated.

Where appropriate, the portfolio contains:

- SQL/PLSQL scripts
- Technical explanations
- Configuration notes
- Troubleshooting notes
- Error messages
- Resolution steps
- Screenshots
- Query results
- Testing and validation

This provides a record of the troubleshooting and problem-solving process
rather than only showing the final successful configuration.
