### Lab 4 - Database Security & Auditing

Implemented additional Oracle database security and monitoring controls.

Hands-on work included:

- Security views
- Database auditing
- Fine-grained auditing (FGA)
- Audit trail analysis
- Stored procedures
- Procedure execution privileges
- Password policies
- Account lockout controls
- Database security testing
- PL/SQL troubleshooting

The documentation includes errors encountered during implementation and
the troubleshooting process used to identify and correct configuration
and PL/SQL issues.
