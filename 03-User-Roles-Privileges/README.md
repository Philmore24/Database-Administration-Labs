### Lab 3 — Database Security: Users, Roles & Privileges

Implemented Oracle database access controls and tested how different
privileges affected database users.

Hands-on work included:

- Creating and deleting users
- Locking and unlocking accounts
- Password expiration
- CREATE SESSION privileges
- System and object privileges
- GRANT and REVOKE
- Database roles
- Role assignment
- Tablespace quotas
- Cross-schema access
- Testing restricted and authorized access

The lab also documents expected permission failures and the administrative
changes used to provide the appropriate access.
